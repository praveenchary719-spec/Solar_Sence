🔴 Before Preprocessing (Raw Ingestion)

Raw Plant_1_Merged_Data
  • • Scale Variance: Unscaled raw values spanning 0 to 7,000,000+ (Total Yield) and 0 to 14,000 (DC Power).
  • • Categorical Strings: High-cardinality alphanumeric strings (e.g. 1BY6WEcLGh8j5v7, HmiyD2TTLFNqEEn).

🟢 After Preprocessing (Engineered State)

Engineered Output
  • • Scale Variance: Standardized with StandardScaler (mean = 0.0, std = 1.0) and MinMax alternatives.
  • • Categorical Encodings: Transformed via Label, Ordinal, One-Hot, and Target Encoders.
  • • Missing Value Imputation: Robust median replacement for numeric, mode for categorical (0 NaN).
  • • Duplicate Scrubbing: 100% deduplicated row continuity.
  • • Model Readiness: Optimal convergence for OLS, Ridge, Lasso, Neural Nets, and Tree Ensembles.
